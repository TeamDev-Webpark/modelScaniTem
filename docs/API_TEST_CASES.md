# คู่มือทดสอบ API (สำหรับ Software tester)

ตรวจล่าสุด: 13 พ.ย. 2026 · API เวอร์ชัน 1.0.0 (`api/`) · ผลรวม **49/49 ผ่าน** (หลังแก้บั๊ก B1–B10) + ทดสอบฐานข้อมูลล่มระหว่างใช้งาน 18/18, ข้อมูลหลัก **ไม่พบปัญหา**

## 1. เตรียมระบบ

1. ติดตั้งแพ็กเกจ (รวมแพ็กเกจของ API แล้ว)
   ```bash
   pip install -r requirements.txt
   ```
2. ตั้ง `DATABASE_URL` ใน `.env` ให้ชี้ PostgreSQL (ใช้กับ endpoint ประวัติ `/api/v1/inspections`)
3. รัน API
   ```bash
   uvicorn api.main:app --host 0.0.0.0 --port 8000
   ```
4. เปิด **http://localhost:8000/docs** (Swagger) ทดสอบทุก endpoint จากหน้านี้ได้เลย หรือใช้ Postman โดย import จาก `http://localhost:8000/openapi.json`

> ⚠️ API ยังไม่มีการยืนยันตัวตน ใครเข้าถึงพอร์ตได้ก็ลบประวัติได้ (`DELETE`) ทดสอบในเครื่องหรือเครือข่ายทดสอบเท่านั้น

## 5. ข้อจำกัดที่ทราบแล้ว (ไม่ใช่บั๊ก)

- **L1** ถาดว่างของ YA 2/2 (16 รายการ) ลายน้อยเกิน ระบบจัดภาพไม่ได้ จึงตอบ "ตรวจซ้ำ" ทุกช่องแทน "หาย"
- **L2** ภาพถ่ายหน้างานจริงยังจัดภาพให้ตรงกับภาพต้นแบบไม่ได้ (ภาพต้นแบบเป็นภาพสตูดิโอ) ต้องถ่ายภาพต้นแบบใหม่จากหน้างาน
- **L3** การจำเครื่องมือชิ้นเดียว (SIFT, เกณฑ์ขั้นต่ำ 8 จุด) อาจตอบ `found` กับภาพที่ไม่ใช่เครื่องมือนั้น หน้า "สแกน" ในแอปใช้เกณฑ์เดียวกันจึงเป็นแบบเดียวกัน
- ข้อความ "0 จุดตรงกัน" ตอนจัดภาพไม่สำเร็จเป็นค่าคงที่ ไม่ใช่จำนวนจริง
